## 🚀 Getting Started

### Prerequisites
- Node.js 14+ or later
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Generate sitemap
npm run build

# Start local development server
npm run dev
```

### Environment Setup

1. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```

2. Update environment variables as needed

## 📝 Available Scripts

- `npm run dev` - Start live-server development environment
- `npm run build` - Generate sitemap and build files
- `npm run generate:sitemap` - Generate XML sitemap
- `npm start` - Start local server

## 🌐 Deployment

### Deploy to Vercel

1. Connect your GitHub repository to Vercel
2. Vercel will automatically detect `vercel.json` configuration
3. Set environment variables in Vercel dashboard
4. Deploy automatically on push to main branch

### Deployment Features

- Automatic sitemap generation during build
- Static file caching optimization
- SPA routing configuration
- Environment variable support
