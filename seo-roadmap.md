# 90-Day SEO Ranking Roadmap

## Week 1
- Submit `https://www.ramnagritourism.com/sitemap.xml` in Google Search Console.
- Request indexing for `blog.html` and all new blog article pages.
- Add internal links from homepage sections to the blog hub and the first Ram Mandir guide.
- Add a Google Business Profile post linking to the first blog: Ram Mandir Ayodhya Travel Guide 2026.

## Week 2-4
- Publish 2 helpful blogs per week around Ayodhya, Ram Mandir, Kashi, Prayagraj, Chitrakoot, cab and hotel keywords.
- Add location keywords naturally, including pickup cities and route combinations.
- Add useful FAQs to every new blog and keep schema aligned with visible content.
- Add Google Business Profile updates that link to fresh guides and tour pages.

## Month 2
- Build and improve destination pages for Ayodhya Tour Package, Kashi Tour Package, Prayagraj Tour Package, Chitrakoot Tour Package and Naimisharanya Tour Package.
- Add internal links from each destination page to relevant blog articles.
- Expand hotel and cab sections with route-specific content.
- Monitor Search Console impressions, queries and indexing coverage weekly.

## Month 3
- Add customer stories from real tours with photos, route details and testimonials.
- Build local backlinks from travel directories, local business listings and partner hotels.
- Add or improve the review section across important service pages.
- Improve Core Web Vitals by compressing images, reducing unused scripts and checking mobile layout shifts.
- Track Search Console queries and update titles, headings and FAQs based on real search demand.
